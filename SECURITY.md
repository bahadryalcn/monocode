# Security

Please **do not** open a public issue for vulnerabilities.

For this fork, contact [the maintainer](https://github.com/bahadryalcn)
privately using the email listed on their profile. GitHub private vulnerability
reporting is not currently enabled for this repository.
Include the release tag or source commit, platform, and enough detail to reproduce.
Do not include live credentials or unrelated private session data.

For the original MonoCode, follow [the upstream security policy](https://github.com/hardbeat920/monocode/blob/main/SECURITY.md).
Identify which repository and build are affected so reports reach the appropriate maintainer.

MonoCode runs the agent CLIs you already have installed. A session can edit files and run commands the same way those tools would in a terminal. Treat a bad prompt like running those CLIs yourself.
